## 1. 系统概述

### 功能定位
后端管理系统的订单管理模块，面向管理员和风控人员查看、分析、管理所有用户的订单。

### 核心功能
- 订单列表查询（分页、搜索、过滤）
- 订单详情查看
- 订单统计分析
- 异常订单处理（取消、备注）
- 数据导出（CSV/Excel）
- 订单时间线跟踪

### 2.3 新建表：订单统计快照

用于快速查询每日/每周统计，避免实时 JOIN 查询性能问题：

**V19__create_order_daily_summary.sql**（在同一个迁移文件中）
```sql
CREATE TABLE IF NOT EXISTS order_daily_summary (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    summary_date DATE NOT NULL,
    
    -- 交易统计
    total_orders INT DEFAULT 0,
    buy_orders INT DEFAULT 0,
    sell_orders INT DEFAULT 0,
    filled_orders INT DEFAULT 0,
    cancelled_orders INT DEFAULT 0,
    rejected_orders INT DEFAULT 0,

    total_sell_qty INT DEFAULT 0,
    total_buy_amount DECIMAL(15,2) DEFAULT 0,
    total_sell_amount DECIMAL(15,2) DEFAULT 0,
    
    -- 费用统计
    total_commission DECIMAL(10,2) DEFAULT 0,
    total_tax DECIMAL(10,2) DEFAULT 0,
    
    -- 盈亏统计
    realized_pnl DECIMAL(15,2) DEFAULT 0,
    
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    PRIMARY KEY (user_id, summary_date),
    INDEX idx_user_date (user_id, summary_date),
    INDEX idx_date (summary_date)
) COMMENT='订单每日汇总统计表';
```

### 3.3 错误码定义

| HTTP | 错误码 | 说明 | 处理 |
|------|--------|------|------|
| 400 | INVALID_PARAMS | 参数错误 | 检查请求参数 |
| 400 | INVALID_STATE | 订单状态不允许操作 | 订单已成交/已取消 |
| 401 | UNAUTHORIZED | 认证失败 | 检查 Token |
| 403 | FORBIDDEN | 权限不足 | 需要 ADMIN 角色 |
| 404 | NOT_FOUND | 订单不存在 | 检查订单ID |
| 500 | INTERNAL_ERROR | 系统错误 | 查看服务器日志 |

```java
@Service
@Slf4j
public class OrderAdminService {
    
    @Autowired private OrderRepository orderRepository;
    @Autowired private UserService userService;
    @Autowired private BrokerAccountService brokerAccountService;
    
    /**
     * 分页查询订单列表
     * @param page 页码
     * @param pageSize 每页数量
     * @param filter 查询过滤条件
     */
    public Page<OrderAdminDto> queryOrders(int page, int pageSize, OrderQueryFilter filter) {
        log.info("Admin querying orders: page={}, pageSize={}, filter={}", page, pageSize, filter);
        try {
            // 构建查询条件
            Pageable pageable = PageRequest.of(page - 1, pageSize, 
                Sort.by(Sort.Direction.DESC, filter.getSortBy()));
            
            // 执行查询
            Page<Order> orderPage = orderRepository.findAll(
                (root, query, cb) -> buildOrderPredicate(root, cb, filter),
                pageable
            );
            
            // 转换 DTO
            return orderPage.map(this::convertToAdminDto);
        } catch (Exception e) {
            log.error("Error querying orders", e);
            throw new BusinessException("查询订单失败", ErrorCode.INTERNAL_ERROR);
        }
    }
    
    /**
     * 获取订单详情
     */
    public OrderAdminDto getOrderDetail(Long orderId) {
        log.info("Fetching order detail: orderId={}", orderId);
        Order order = orderRepository.findById(orderId)
            .orElseThrow(() -> new BusinessException("订单不存在", ErrorCode.NOT_FOUND));
        return convertToAdminDto(order);
    }
    
    /**
     * 标记订单（风险标记或备注）
     */
    @Transactional
    public OrderAdminDto markOrder(Long orderId, String riskFlag, String adminNote, Long adminId) {
        log.warn("Admin marking order: orderId={}, riskFlag={}, adminId={}", orderId, riskFlag, adminId);
        
        Order order = orderRepository.findById(orderId)
            .orElseThrow(() -> new BusinessException("订单不存在", ErrorCode.NOT_FOUND));
        
        order.setRiskFlag(riskFlag);
        order.setAdminNote(adminNote);
        order.setAdminId(adminId);
        order.setAdminActionTime(LocalDateTime.now());
        
        Order updated = orderRepository.save(order);
        log.info("Order marked successfully: orderId={}, riskFlag={}", orderId, riskFlag);
        
        return convertToAdminDto(updated);
    }
    
    /**
     * 取消异常订单（仅管理员）
     */
    @Transactional
    public OrderAdminDto cancelOrder(Long orderId, String reason, Long adminId) {
        log.warn("Admin cancelling order: orderId={}, reason={}, adminId={}", orderId, reason, adminId);
        
        Order order = orderRepository.findById(orderId)
            .orElseThrow(() -> new BusinessException("订单不存在", ErrorCode.NOT_FOUND));
        
        // 检查订单状态是否允许取消
        if ("FILLED".equals(order.getStatus()) || "CANCELLED".equals(order.getStatus())) {
            log.error("Cannot cancel order with status: {}", order.getStatus());
            throw new BusinessException("订单状态不允许取消", ErrorCode.INVALID_STATE);
        }
        
        order.setStatus("CANCELLED");
        order.setRiskFlag("CANCELLED_BY_ADMIN");
        order.setAdminNote(reason);
        order.setAdminId(adminId);
        order.setAdminActionTime(LocalDateTime.now());
        
        Order updated = orderRepository.save(order);
        log.info("Order cancelled by admin successfully: orderId={}", orderId);
        
        return convertToAdminDto(updated);
    }
```

```java
@RestController
@RequestMapping("/admin/orders")
@Slf4j
@PreAuthorize("hasRole('ADMIN')")
public class OrderAdminController {
    
    @Autowired private OrderAdminService orderAdminService;
    @Autowired private AuthService authService;
    
    /**
     * 获取订单列表
     */
    @GetMapping
    public ResponseEntity<ApiResponse<Page<OrderAdminDto>>> queryOrders(
            @RequestParam(defaultValue = "1") int page,
            @RequestParam(defaultValue = "20") int pageSize,
            @RequestParam(required = false) Long userId,
            @RequestParam(required = false) String status,
            @RequestParam(required = false) String symbol,
            @RequestParam(required = false) String side,
            @RequestParam(required = false) String riskFlag,
            @RequestParam(required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) LocalDate startDate,
            @RequestParam(required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) LocalDate endDate,
            @RequestParam(defaultValue = "created_at") String sortBy,
            @RequestParam(defaultValue = "desc") String sortOrder) {
        
        log.info("Admin querying orders: page={}, pageSize={}, userId={}, status={}", 
                page, pageSize, userId, status);
        
        OrderQueryFilter filter = OrderQueryFilter.builder()
            .userId(userId)
            .status(status)
            .symbol(symbol)
            .side(side)
            .riskFlag(riskFlag)
            .startDate(startDate)
            .endDate(endDate)
            .sortBy(sortBy)
            .sortOrder(sortOrder)
            .build();
        
        Page<OrderAdminDto> result = orderAdminService.queryOrders(page, pageSize, filter);
        return ResponseEntity.ok(ApiResponse.success(result));
    }
    
    /**
     * 获取订单详情
     */
    @GetMapping("/{orderId}")
    public ResponseEntity<ApiResponse<OrderAdminDto>> getOrderDetail(@PathVariable Long orderId) {
        log.info("Fetching order detail: orderId={}", orderId);
        OrderAdminDto order = orderAdminService.getOrderDetail(orderId);
        return ResponseEntity.ok(ApiResponse.success(order));
    }
    
    /**
     * 标记订单
     */
```

## 6. 日志记录策略

### 6.1 关键位置日志

| 位置 | 日志级别 | 内容 | 目的 |
|------|---------|------|------|
| 订单查询 | INFO | 操作员ID、查询条件、返回条数 | 审计追踪 |
| 标记订单 | WARN | 订单ID、旧值→新值、操作人 | 监控管理员操作 |
| 取消订单 | WARN | 订单ID、原因、操作人 | 监控风险管理 |
| 异常订单 | ERROR | 订单ID、错误信息、堆栈 | 问题诊断 |
| 导出数据 | INFO | 导出人、导出条数、时间段 | 数据审计 |

### 6.2 建议的日志语句

已在上面的代码中标注，关键位置包括：
```java
log.info("Admin querying orders: ...")      // 查询
log.warn("Admin marking order: ...")        // 标记（敏感操作）
log.warn("Admin cancelling order: ...")     // 取消（敏感操作）
log.error("Error querying orders", e)       // 错误处理
log.error("Cannot cancel order with status: {}", status)  // 业务错误
```
