## 📝 本次更新内容

### 1. 窗体控制按钮功能修复 ✅

**问题**: 最小化、最大化、关闭按钮显示正常但点击无效应  
**根本原因**: 窗体方法调用使用了同步方式，但 `windowManager` 的方法是异步的

**修复步骤**:

1. **修改回调类型定义** (line ~420)
   ```dart
   // 旧:
   final VoidCallback onPressed;
   
   // 新:
   final Future Function() onPressed;
   ```

2. **更新 _WindowControls build 方法** (line ~370-395)
   ```dart
   // 旧:
   onPressed: () => windowManager.minimize(),
   
   // 新:
   onPressed: () async {
     await windowManager.minimize();
   },
   ```

3. **修复所有三个按钮**:
   - 最小化: `await windowManager.minimize()`
   - 最大化/恢复: `_toggleMaximize` (已是 async)
   - 关闭: `await windowManager.close()`

**验证**: 
- ✅ 代码编译通过 (0 errors, 7 warnings)
- ✅ 应用启动成功
- 🔄 待测试: 点击按钮后窗体应正确响应

### 2. 底部状态栏右对齐修复 ✅

**问题**: 更新时间和连接状态不在右边，始终跟着市场指数

**根本原因**: 使用了 `Spacer()` + `Flexible()` 组合，但嵌套结构不正确

**修复步骤** (line ~1945-1985):

原结构:
```dart
Row(
  children: [
    _StatusItem(...),  // 市场指数
    const Spacer(),    // ❌ 无效
    Flexible(
      child: SingleChildScrollView(
        child: Row(       // 时间状态
```

新结构:
```dart
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,  // 关键改动!
  children: [
    Flexible(
      flex: 1,
      fit: FlexFit.tight,
      child: SingleChildScrollView(
        scrollDirection: Axis.horizontal,
        child: Row(
          children: [
            _StatusItem(...),  // 市场指数在左
```

    Row(
      mainAxisSize: MainAxisSize.min,
      children: [
        Text(...),        // 时间状态始终右侧
```

**改动详情**:
- 使用 `mainAxisAlignment: MainAxisAlignment.spaceBetween` 将左右内容推到两端
- 左侧: 可滚动的市场指数 (用 `Flexible + SingleChildScrollView`)
- 右侧: 固定的时间+连接状态 (用 `Row with mainAxisSize.min`)

**验证**: 
- ✅ 代码编译通过
- 🔄 待测试: 窗口拉伸时，时间状态应始终在右端

### 3. 统一组件圆角为 5px 🎯

**问题**: Dashboard 中部分卡片与控件使用不同圆角（3/4/6/8/10/12/14px），视觉不一致。

**修复**: 将 `lib/features/desktop/desktop_dashboard.dart` 中所有 `BorderRadius.circular(...)` 统一替换为 `5`，保证界面圆角一致。
