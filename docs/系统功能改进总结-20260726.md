## 🔄 业务流程

### 初始化流程
```
管理员创建用户 
  → 在 BrokerAccountList 创建/选择券商账户
  → 在 UserBrokerBinding 为用户绑定账户
  → 用户状态：绑定账户 ✓
```

### 切换账户流程
```
管理员访问 UserBrokerBinding
  → 选择用户
  → 显示当前绑定账户信息
  → 从 ACTIVE 账户中选择新账户
  → 点击"切换"
  → 系统：解绑旧账户 + 绑定新账户
  → 用户刷新客户端
  → 客户端调用 /api/v1/trade/current-account
  → 获取新账户信息和 API 环境
  → 自动切换到新账户
```

### 交易端使用流程 (待完成)
```
用户登录交易客户端
  → 客户端查询 GET /api/v1/trade/current-account
  → 获取：账户号、API 环境（LIVE/SANDBOX）
  → 交易时使用对应环境的端点
```

## 🛡️ 关键特性

### 一对一关系保证
- 通过 `users.current_broker_account_id` 的 FK 约束
- 同一个账户最多被一个用户持有
- 账户删除时自动解绑 (ON DELETE SET NULL)

### 验证规则
- ✅ 用户存在性检查
- ✅ 账户 ACTIVE 状态验证
- ✅ 账户重复绑定防护
- ✅ 事务保证原子性

### 查询优化
```sql
-- 列表查询包含 3 个 LEFT JOIN
SELECT a.*, u.username, b.*, u_bind.username 
FROM t_broker_account a
LEFT JOIN users u ON a.user_id = u.id              -- 创建者
LEFT JOIN t_broker b ON a.broker_id = b.id         -- 券商
LEFT JOIN users u_bind ON a.id = u_bind.current_broker_account_id  -- 使用者
```

### 前端状态管理
- 选中用户自动触发当前账户查询
- 切换操作前确认对话框
- 成功后自动刷新展示最新绑定关系
