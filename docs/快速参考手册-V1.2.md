# FlashTrade 一对一绑定系统 - 快速参考手册

**版本**: 1.2 | **日期**: 2026-07-26 | **主题**: 用户-券商账户绑定

---

## 🎯 核心功能速览

### 数据模型

```
用户表 (users)
├── id
├── username
├── current_broker_account_id ← 外键指向当前绑定账户
└── ...

券商账户表 (t_broker_account)
├── id
├── user_id (创建者)
├── account_no
├── api_environment (LIVE/SANDBOX)
├── status (ACTIVE/SUSPENDED/CLOSED)
└── ...

约束: 一对一关系
  users.current_broker_account_id → t_broker_account.id
  (每个账户最多被一个用户绑定)
```

## 📡 API 端点速查

### 交易端 API (客户端使用)

| 端点 | 方法 | 功能 | 权限 |
|------|------|------|------|
| `/api/v1/trade/current-account` | GET | 查询用户当前账户和 API 环境 | TRADER |
| `/api/v1/trade/order` | POST | 下单 | TRADER |
| `/api/v1/trade/order/{id}/status` | GET | 查询委托状态 | TRADER |

### 管理员 API

| 端点 | 方法 | 功能 | 权限 |
|------|------|------|------|
| `/admin/broker-accounts` | GET | 列表：包含当前使用者 | ADMIN |
| `/admin/broker-accounts/{id}` | GET | 详情 | ADMIN |
| `/admin/broker-accounts` | POST | 创建 | ADMIN |
| `/admin/broker-accounts/{id}` | PUT | 更新 | ADMIN |
| `/admin/broker-accounts/{id}` | DELETE | 停用 | ADMIN |
| `/admin/broker-accounts/user/{userId}/current` | GET | 查询用户当前账户 | ADMIN |
| `/admin/broker-accounts/user/{userId}/bind/{accountId}` | POST | 为用户切换账户 | ADMIN |

## 🔧 一对一绑定关键操作

### 绑定账户

```bash
# 为用户 5 绑定账户 2
POST /admin/broker-accounts/user/5/bind/2
Authorization: Bearer {token}

# 响应：
{
  "success": true,
  "data": {
    "id": 2,
    "accountNo": "987654321",
    "currentBindingUsername": "trader01"
  }
}
```

**绑定流程**:
1. 验证用户和账户存在
2. 验证账户状态为 ACTIVE
3. 检查账户是否被其他用户占用
4. 自动解绑用户的旧账户
5. 设置新绑定

### 查询用户当前账户

```bash
# 方式 1: 客户端查询自己的账户
GET /api/v1/trade/current-account
Authorization: Bearer {token}

# 方式 2: 管理员查询指定用户的账户
GET /admin/broker-accounts/user/{userId}/current
Authorization: Bearer {token}

# 响应字段重点:
{
  "id": 1,
  "accountNo": "123456789",
  "brokerName": "E*TRADE",
  "apiEnvironment": "LIVE",        ← 关键：用于选择 API 端点
  "status": "ACTIVE",
  "currentBindingUsername": "trader01"
}
```

### 获取账户列表（含绑定用户）

```bash
GET /admin/broker-accounts
Authorization: Bearer {token}

# 响应：
[
  {
    "id": 1,
    "accountNo": "123456789",
    "currentBindingUsername": "trader01"  ← 已绑定
  },
  {
    "id": 2,
    "accountNo": "987654321",
    "currentBindingUsername": null        ← 未绑定
  }
]
```

## 📊 数据库快速查询

### 查看用户绑定情况
```sql
SELECT 
  u.id, u.username, u.current_broker_account_id,
  a.account_no, a.broker_id, a.api_environment
FROM users u
LEFT JOIN t_broker_account a ON u.current_broker_account_id = a.id
ORDER BY u.id;
```

### 查看账户绑定情况
```sql
SELECT 
  a.id, a.account_no, a.broker_id, a.api_environment,
  u.username AS bound_user
FROM t_broker_account a
LEFT JOIN users u ON a.id = u.current_broker_account_id
ORDER BY a.id;
```

### 未绑定的账户
```sql
SELECT id, account_no, broker_id
FROM t_broker_account a
WHERE NOT EXISTS (
  SELECT 1 FROM users u WHERE u.current_broker_account_id = a.id
);
```

### 未绑定的用户
```sql
SELECT id, username
FROM users
WHERE current_broker_account_id IS NULL;
```

## 🔍 状态码速查

| 代码 | 含义 | 场景 |
|------|------|------|
| 200 | 成功 | 正常操作 |
| 400 | 参数错误 | 环境值无效、账户已占用 |
| 401 | 认证失败 | Token 无效或过期 |
| 403 | 权限不足 | 非 ADMIN 用户 |
| 404 | 资源不存在 | 用户/账户 ID 不存在 |
| 500 | 服务器错误 | 数据库操作失败 |

## 🐛 常见问题速解

| 问题 | 症状 | 快速解决 |
|------|------|--------|
| 无法绑定账户 | 返回"已被占用" | 检查数据库中是否已有绑定 |
| 查询返回 null | 环境字段为空 | 编辑账户，选择 API 环境并保存 |
| 前端未更新 | 绑定后列表无变化 | 手动刷新页面或检查代码中是否调用了刷新方法 |
| 迁移失败 | 字段不存在 | 检查 V18 迁移文件，重启应用 |
| 数据不一致 | 查询多个绑定 | 执行 UPDATE 修复数据 |

## 📱 客户端集成流程

```
1. 用户登录
   ↓
2. 获取 Token
   ↓
3. 调用 GET /api/v1/trade/current-account
   ↓
4. 解析响应中的 apiEnvironment (LIVE/SANDBOX)
   ↓
5. 根据环境初始化 BrokerClient
   ↓
6. 用户在交易界面操作
   ↓
7. 若用户切换账户（管理端操作）
   ↓
8. 客户端重新查询 current-account
   ↓
9. 检测到环境/账户变化 → 重新初始化客户端
```
