# FlashTrade 项目前期讨论记录

> 这份说明用于汇总项目启动阶段的核心决策，并修复此前因编码损坏导致的乱码内容。

## 项目定位
FlashTrade 是一个面向交易场景的系统项目，目标是提供统一的账户、持仓、订单、成交与实时推送能力。

## 关键决策
- 后端使用 Java 21 与 Spring Boot 3.5.7。
- 推荐使用 Microsoft Build of OpenJDK 21。
- 数据库与缓存分别使用 MySQL 8.0 与 Redis 7.x。
- 使用 Spring Security + JWT 实现认证与权限控制。
- 通过 Docker Compose 提供本地开发环境与基础部署能力。

## 后续重点
1. 搭建 Maven 项目骨架。
2. 完成数据库迁移与核心表结构。
3. 实现认证、订单、持仓与账户相关 API。
4. 逐步补全测试、文档与部署配置。
