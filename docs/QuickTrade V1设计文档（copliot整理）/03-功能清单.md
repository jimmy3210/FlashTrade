## 3. 桌面主界面 UI 细节

主界面布局内容参考 `Main-UI.png`，主要包含以下模块：

- 左侧垂直导航栏
  - Dashboard
  - Watchlist
  - Positions
  - Orders
  - Account
  - Settings
  - Logout

- 顶部全局信息区
  - QuickTrade 应用标志
  - 股票检索框（Search symbol...）
  - Market Open 状态与当前时间
  - Buying Power 显示
  - Cash 显示
  - Account 信息（账号后四位）
  - 通知图标
  - 设置图标
  - 用户头像和用户名

- 左侧 Watch List 区域
  - 占据左侧整列
  - 标题：Watch List
  - 列表字段：Symbol / Last / Chg %
  - 自选股行项：AAPL、TSLA、NVDA、AMD、META、AMZN、MSFT、GOOGL、SXTC、OMH
  - 提供新增股票按钮和更多操作菜单
  - 底部可进入“Edit Watchlist”编辑页面

- 中央行情概览区
  - 当前选中股票代码与名称：AAPL · Apple Inc. · NASDAQ
  - 当前价格及涨跌值：212.35，+2.35 (+1.12%)
  - Bid / Ask / Spread / Bid Size / Ask Size 数据
  - 价格统计字段：Open / High / Low / Prev Close / Volume / Avg Vol (10D)
  - 时间区间切换：1D / 5D / 1M / 3M / 6M / YTD / 1Y / 5Y / All
  - Day Range 和 52 Week Range 滑动刻度条

- 右侧 Order Entry 区域
  - Buy / Sell 切换按钮
  - Order Type 下拉选择（当前显示 Market）
  - Quantity 输入项
  - Time In Force 选择（Day）
  - Estimated Amount 显示
  - Preview Buy Order 按钮
  - Preview Sell Order 按钮

- 底部中段功能区
  - Positions 模块
    - 显示 Symbol / Qty / Avg Price / Market Value / Day P/L / P/L %
    - 示例持仓：AAPL、TSLA、SXTC、OMH
    - 显示 Total Market Value
  - Orders 模块
    - Tab 分类：Working / Filled / Cancelled / All
    - Orders 列表项：Symbol / Side / Qty / Type / Price / TIF / Time
    - 示例订单：AAPL Buy、TSLA Sell、NVDA Buy
    - View All Orders 链接
  - Account Summary 模块
    - Net Liquidation
    - Cash Balance
    - Buying Power
    - Day P/L
    - YTD P/L

- 底部状态条
  - 市场指数行情：DOW / S&P 500 / NASDAQ / VIX
  - 指数变化百分比显示
  - 数据时间戳（Data as of）
  - 连接状态指示（Connected）

以下功能暂不纳入 V1：

- Time & Sales
