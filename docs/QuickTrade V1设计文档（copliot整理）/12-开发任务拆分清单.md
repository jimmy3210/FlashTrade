# 12-开发任务拆分清单

## 1. 目标

本文件用于把 QuickTrade V1 的开发工作拆分成清晰的任务项，方便后端、前端、测试和产品协同推进。

## 2. 开发阶段划分

### 阶段 1：基础准备

- 确认 V1 功能边界
- 确认统一数据模型和接口格式
- 确认 Broker Adapter 的接入方式
- 初始化项目结构与基础配置

### 阶段 2：后端基础能力

- 实现认证与会话管理
- 实现行情查询服务
- 实现订单服务
- 实现持仓与账户服务
- 实现 WatchList 服务
- 完成 Broker Adapter 接口封装

### 阶段 3：前端页面实现

- 完成 Header 区域
- 完成 WatchList 页面
- 完成 Quote 页面
- 完成 Order Entry 页面
- 完成 Positions / Orders / Account Summary 页面
- 接入统一接口与状态管理

### 阶段 4：联调与测试

- 完成前后端接口联调
- 完成异常流程测试
- 完成交易流程测试
- 完成 UI 交互测试
- 形成 V1 验收清单

## 3. 任务清单

### 3.1 后端任务

| 任务 | 说明 |
| --- | --- |
| 建立统一响应格式 | 统一成功 / 错误返回结构 |
| 实现登录服务 | 建立 Broker 会话 |
| 实现行情服务 | 提供实时行情接口 |
| 实现订单服务 | 提供下单、撤单、改单能力 |
| 实现持仓服务 | 提供持仓查询能力 |
| 实现账户服务 | 提供账户摘要、现金、购买力能力 |
| 实现 WatchList 服务 | 提供自选股增删查能力 |
| 实现 Adapter 层 | 适配 Schwab / Tastytrade |

### 3.2 前端任务

| 任务 | 说明 |
| --- | --- |
| 页面布局搭建 | 实现整体三栏主布局 |
| Header 组件 | 展示 Logo、搜索、市场状态、用户信息 |
| WatchList 组件 | 展示自选股列表 |
| Quote 组件 | 展示行情详情 |
| Order Entry 组件 | 展示买卖下单表单 |
| Positions / Orders / Account Summary 组件 | 展示底部信息面板 |
| 状态管理与接口对接 | 连接后端接口 |

### 3.3 测试任务

| 任务 | 说明 |
| --- | --- |
| 登录流程测试 | 验证账户登录与会话建立 |
| 行情刷新测试 | 验证行情接口与 UI 刷新 |
| 下单流程测试 | 验证买卖提交与结果反馈 |
| 持仓查询测试 | 验证持仓展示正确 |
| 异常处理测试 | 验证 Broker 失败或网络异常 |

## 4. 推荐优先级

1. 先做登录、行情、订单、持仓、账户这五个核心闭环
2. 再完成 UI 页面和交互细节
3. 最后补测试与验收项

## 5. 交付标准

V1 可视为基本完成的标准包括：

- 用户可登录 Broker 账户
- 用户可查看实时行情
- 用户可完成买入 / 卖出
- 用户可查看持仓与账户摘要
- 前后端联调通过
- 文档与实现基本一致
