## 文档用途

这套文档面向以下角色：

- 产品与交互设计：理解 V1 的目标、界面结构与功能边界
- 前端开发：确认 UI 结构、交互行为与数据展示要求
- 后端开发：确认服务边界、接口职责与 Adapter 设计
- 测试与交付：作为 V1 功能验收与迭代管理的依据

## 建议阅读顺序

1. 先阅读项目定位与目标
2. 再阅读 UI 设计说明书
3. 然后查看功能清单与 API 对照表
4. 接着阅读字段映射、接口设计与系统架构
5. 最后结合开发任务与验收清单推进实施

## 使用建议

- 如果你是产品或设计人员，优先阅读 01～03 和 15
- 如果你是前端开发人员，优先阅读 02、03、04、09 和 15
- 如果你是后端开发人员，优先阅读 04、05、09、10、11 和 15
- 如果你是测试或交付负责人，优先阅读 12、13 和 14
