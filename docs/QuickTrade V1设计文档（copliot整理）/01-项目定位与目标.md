# 01-项目定位与目标

## 1. 项目定位

QuickTrade 是面向美股交易场景的交易系统，提供自有 UI 和统一 API。UI 的交易与查询通过系统 API 调用后端；其他获授权的 API 消费方也使用同一套 API 和后台服务。后台通过统一服务层和 Broker Adapter 对接不同券商及其他交易 API 提供方，不为 UI 或不同消费方另建后台。当前产品范围仅限美股交易；具体支持哪些提供方，以实际完成并验证的 API 接入为准。

## 2. 产品定位

QuickTrade 不是一个完整的专业交易平台，而是一个面向个人和轻量使用场景、同时提供 UI 与 API 的统一交易系统。它的重点是：

- 快速查看实时行情
- 简洁完成买卖操作
- 清晰展示持仓和账户摘要
- 通过系统自有 UI 与统一 API 提供美股交易和查询能力
- 通过同一后台的适配层接入多个美股交易 API

## 3. 设计目标

QuickTrade V1 的目标包括：

- 以实时行情和交易操作为核心
- 保持界面简洁，减少不必要的操作步骤
- 优先保证“可用性”和“稳定性”，而非追求复杂分析能力
- 通过统一服务层和 Adapter 设计，实现与不同券商及交易 API 提供方的解耦
- 为后续扩展打下可维护的基础

## 4. V1 范围

V1 重点覆盖以下能力：

- 登录 Broker 账户
- 股票搜索
- 实时报价
- 买入 / 卖出
- 撤单 / 改单
- 当前持仓查看
- 未成交与已成交订单查看
- 账户现金、购买力与资产摘要查看
- 自选股管理

## 5. V1 不做的内容

以下内容明确不纳入 V1：

- K 线图
- 分时图
- Time & Sales
- Level 2 / Market Depth
- 新闻资讯
- 热图与扫描器
- 技术指标分析
- 复杂条件单与高级策略工具

## 6. 设计原则

QuickTrade V1 采用以下设计原则：

- UI 和外部 API 消费方都只调用 QuickTrade API，不直接依赖 Broker 原始接口
- UI 只展示 Broker 能提供的数据：避免出现“假数据”或占位功能
- UI 与 API 共用同一套后台服务；Broker 差异由 Adapter 层封装
- 界面以深色主题为主，适配长时间盯盘场景
- 优先保证实用性与可扩展性，而非追求功能堆砌

## 7. 适用场景

V1 适合用于：

- 个人投资者的日常盯盘
- 快速查看账户与持仓
- 简化交易操作流程
- 在不改变 UI 和统一 API 核心契约的前提下，接入更多提供美股交易能力的 API 提供方
