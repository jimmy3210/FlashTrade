# 01-项目定位与目标

## 1. 项目定位

QuickTrade 是面向股票交易场景的轻量化客户端，目标是在不引入复杂分析工具的前提下，提供快速、清晰、稳定的交易体验。它强调“核心功能先行”，让用户能够在最短路径内完成：查看行情、下单、查看持仓和账户状态。

## 2. 产品定位

QuickTrade 不是一个完整的专业交易平台，而是一个面向个人和轻量使用场景的交易界面入口。它的重点是：

- 快速查看实时行情
- 简洁完成买卖操作
- 清晰展示持仓和账户摘要
- 为后续接入多个 Broker 提供统一抽象

## 3. 设计目标

QuickTrade V1 的目标包括：

- 以实时行情和交易操作为核心
- 保持界面简洁，减少不必要的操作步骤
- 优先保证“可用性”和“稳定性”，而非追求复杂分析能力
- 通过统一服务层和 Adapter 设计，实现与不同 Broker 的解耦
- 为后续扩展打下可维护的基础

## 4. V1 范围

V1 重点覆盖以下能力：

- 登录 Broker 账户
- 股票搜索
- 实时报价
- 买入 / 卖出
- 撤单 / 改单
- 当前持仓查看
- 未成交与已成交订单查看
- 账户现金、购买力与资产摘要查看
- 自选股管理

## 5. V1 不做的内容

以下内容明确不纳入 V1：

- K 线图
- 分时图
- Time & Sales
- Level 2 / Market Depth
- 新闻资讯
- 热图与扫描器
- 技术指标分析
- 复杂条件单与高级策略工具

## 6. 设计原则

QuickTrade V1 采用以下设计原则：

- UI 不直接依赖 Broker：前端只消费 QuickTrade 的统一数据模型
- UI 只展示 Broker 能提供的数据：避免出现“假数据”或占位功能
- 统一服务层负责对接不同 Broker：Broker 差异封装在 Adapter 层
- 界面以深色主题为主，适配长时间盯盘场景
- 优先保证实用性与可扩展性，而非追求功能堆砌

## 7. 适用场景

V1 适合用于：

- 个人投资者的日常盯盘
- 快速查看账户与持仓
- 简化交易操作流程
- 未来接入更多 Broker 的基础平台
