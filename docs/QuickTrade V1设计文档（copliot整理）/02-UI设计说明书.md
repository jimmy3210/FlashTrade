# 02-UI设计说明书

## 1. 设计目标

QuickTrade V1 的 UI 目标是“让用户用最少的步骤完成最常见的交易动作”。界面结构要尽可能简洁，重点突出行情、下单和账户信息。
### 1.1 国际化与本地化

- **默认语言**：简体中文 (zh_CN)
- **当前实现**：使用 `intl` + `AppLocalizations` 提供中文字符串
- **界面语言**：所有界面文本、按钮标签、提示、错误消息均使用简体中文
- **数据展示**：数字格式、日期格式、货币符号等遵循中国地区习惯
- **扩展计划**：V2 版本可考虑支持英文、繁体中文等
## 2. 页面整体布局

建议采用三栏主布局，并在底部提供持仓、订单和账户摘要区域。

```text
┌──────────────────────────────────────────────────────────────┐
│ Header                                                       │
├──────────────┬──────────────────────┬────────────────────────┤
│ Watch List   │ Quote / Chart        │ Order Entry            │
├──────────────┼──────────────────────┼────────────────────────┤
│ Positions    │ Orders               │ Account Summary        │
└──────────────┴──────────────────────┴────────────────────────┘
```

### 2.1 布局说明

- 左侧：显示自选股列表与关键行情摘要
- 中间：显示选中股票的报价、基础信息与核心详情
- 右侧：提供买入/卖出输入与提交入口
- 底部：显示持仓、订单与账户摘要，便于快速查看状态

## 3. 各区域说明

### 3.1 Header

Header 用于显示全局状态和用户信息，包含：

- Logo
- Search
- Market Status
- User
- Account
- Cash
- Buying Power

### 3.2 Watch List

Watch List 负责展示用户关注的股票，显示字段包括：

- Symbol
- Last
- Change
- Change %

交互规则：

- 点击某只股票后，Quote 区域更新
- 支持添加、删除和排序自选股

### 3.3 Quote

Quote 区域显示选中股票的核心行情信息，包括：

- Symbol
- Company Name
- Last Price
- Bid
- Ask
- Open
- High
- Low
- Previous Close
- Volume
- 52 Week High
- 52 Week Low

### 3.4 Order Entry

Order Entry 是交易核心区域，包含：

- Buy / Sell 切换
- Price
- Qty
- Order Type
- Time In Force
- Preview
- Submit

### 3.5 Positions / Orders / Account Summary

底部区域分为三个子模块：

- Positions：显示持仓数量、均价、市值和浮盈亏
- Orders：显示未成交、已成交、已撤销和拒绝订单
- Account Summary：显示现金、购买力、总资产和账户价值

## 4. 交互行为

- 点击 Watch List 中的股票时，Quote 面板切换到该股票
- 买卖操作默认以当前报价为参考
- 提交订单前提供预览确认，降低误操作风险
- 订单状态更新后自动刷新列表

## 5. 视觉规范

### 5.1 主题

- 主题：Dark Theme
- 背景：#1A1D23
- 文字：#FFFFFF
- 涨幅：#00C853
- 跌幅：#F44336
- 买入按钮：绿色
- 卖出按钮：红色

### 5.2 字体

- 主字体：微软雅黑 / Inter
- 数字字体：JetBrains Mono

## 6. 刷新策略

为保证界面实时性，建议采用以下刷新频率：

- Quote：1 秒
- Orders：5 秒
- Positions：5 秒
- Account：10 秒

## 7. 设计原则

- 以交易场景优先，而非信息堆叠
- 重要信息优先展示，次要信息收起或分组显示
- 交互路径尽可能短，减少操作步骤
- 保持统一的视觉层级和状态反馈

既然目标是“**专业感**”，你需要摆脱那种“把移动端 UI 直接塞进宽屏桌面”的廉价感。桌面端应用的核心竞争力在于：**信息密度、操作响应、以及与操作系统的视觉融合**。

以下是实现“专业感”的三个核心阶梯，你可以根据当前的开发进度选择切入点：

### 1. 战略层面：从“移动端思维”转向“桌面端思维”

专业感来源于用户对软件的“信任感”。如果你想让应用看起来像专业工具，必须处理好以下细节：

* **彻底自定义标题栏**：Windows 默认的标题栏是 Flutter Windows 应用“土味”的源头。一定要用 `bitsdojo_window` 彻底将其隐藏，并换成你自己设计的简洁标题栏。这能让应用瞬间获得“非 Web 包装器”的质感。
* **桌面交互逻辑**：桌面端不是“点”的艺术，而是“悬停”的艺术。
* 所有的可点击元素，**务必**要有 `onHover` 效果（例如轻微改变背景颜色、阴影或光标变为手型）。
* 抛弃移动端的长按、下拉刷新，改用右键菜单 (`ContextMenu`) 和键盘快捷键。


* **留白与密度**：桌面端屏幕宽，信息量大。不要用移动端的 `ListTile`，改用 `DataTable` 或自定义更精简的组件。专业应用往往会有较多的信息展示，保持足够的 Padding 配合精细的字体权重（Font Weight）是提升高级感的捷径。

### 2. 技术层面：方案可行性评估与最优推荐

本节针对“专业感”桌面端改造，评估三种可行方案，并给出当前项目的最优选择。

#### 方案 A：追求极度原生（Fluent UI 风格）

优点：
* 与 Windows 11 视觉高度统一，系统感强。
* Fluent UI 提供原生风格控件、导航与交互惯例，开发时部分样式可直接复用。

缺点：
* 需要引入新的 UI 框架，现有 Material 3 组件需要重构或桥接。
* 设计语言与当前移动/Material 风格存在较大差异，后续维护成本较高。
* 适合明确定位为“Windows 原生工具”的产品。

#### 方案 B：追求现代品牌感（自定义 Material 3 设计）

优点：
* 保持现有 Material 3 项目结构，改造成本低。
* 可灵活塑造品牌风格，适合已有设计体系的产品。
* 通过统一色彩、阴影和交互细节，也能达到较高的专业感。

缺点：
* 若仅沿用移动端布局，仍可能出现“宽屏桌面”与“发育不良”的感觉。
* 需要额外补强桌面交互和窗口融合，否则专业感会不够彻底。

#### 方案 C：现有 Material 3 基础上的桌面专用落地（当前最优方案）

优点：
* 以当前项目已有 Material 3 结构为基础，最大程度复用现有页面、主题与路由。
* 直接补齐桌面核心要素：自定义标题栏、左侧导航、鼠标悬停、键盘快捷、可见滚动条、桌面信息密度。
* 对开发周期最友好，适合“先上线桌面专业版，再迭代细化”的策略。

缺点：
* 仍需精心设计布局与交互，不能仅靠简单改色或卡片圆角来“伪装”桌面感。

#### 最优方案选择：方案 C

推荐当前优先采用方案 C，即“保留 Material 3，补齐桌面化细节”。理由如下：

* 当前工程已经是 Material 3 结构，改造成本最小。
* 方案 C 能最快把“移动端粗糙感”去掉，同时保持品牌统一性。
* 对于希望率先上线并后续迭代的产品，方案 C 最易于实践，也最容易控制风险。

##### 方案 C 的关键落地点

1. **自定义桌面标题栏**
   * 使用 `bitsdojo_window` 或 `window_manager` 隐藏系统默认标题栏。
   * 在顶栏添加 Logo、页面标题、最小化/最大化/关闭按钮，并保持拖拽区域。
2. **左侧导航与大屏布局**
   * 将底部导航替换为左侧 `NavigationRail` / `Sidebar`。
   * 中间区域显示 Quote / Chart，右侧放置 Order Entry，底部固定 Positions / Orders / Account Summary。
3. **桌面交互与渲染细节**
   * 增加 `hover` 效果、可见滚动条、键盘快捷键、右键菜单等桌面习惯。
   * 用 `DataTable` 或自定义表格展示持仓/订单，而不是移动式 `ListTile`。
4. **视觉融合与系统感**
   * 保留深色主题，但使用更精细的层级和更窄的卡片间距。
   * 让窗口顶栏、侧边栏和主内容区看起来像一个整体，而不是多个“堆叠的移动卡片”。

这个方案在当前项目阶段最具可行性：它兼顾现有结构、开发成本和专业视觉感。
### 3. 给你的“专业化”改造清单

你可以先挑其中 2-3 个点进行改造，效果立竿见影：

1. **引入 `bitsdojo_window**`：先干掉 Windows 那个难看的白色顶栏。
2. **固定布局**：将底部的 `BottomNavigationBar` 全部换成左侧的 `NavigationRail` 或 `Sidebar`。
3. **视觉权重**：检查应用内的所有按钮。专业的桌面应用通常会将“主要动作”高亮，而将“次要动作”弱化（使用 `OutlinedButton` 或 `TextButton`），而不是清一色的实心填充按钮。
4. **滚动条体验**：默认的滚动条太细了，在 `ThemeData` 中自定义 `ScrollbarTheme`，使其在鼠标悬停时变粗，或者在滚动时自动显现。

登录页UI设计

这是一个非常典型的“通过增加环境层级和微交互来提升质感”的 UI 升级需求。目前的登录页确实显得比较“平”和孤立。

要打造现在桌面 App 流行的、专业的登录页，我们不应只关注那个白色的登录框，而应该关注**整个窗口的氛围和体验**。

以下是我为您构思的专业化设计方案，以及具体的实现建议：

### 流行趋势设计方案：沉浸式亚克力与悬浮视窗

这个设计方案的目标是让登录页看起来不仅是一个功能界面，更像是一个启动器。

#### 视觉描述：

1. **整体背景（沉浸式体验）**：
* **壁纸**：放弃纯黑色背景。使用一张高质量、深色调的、带有微妙光影变化的抽象城市夜景或科技纹理作为背景（例如，类似 Windows 11 默认壁纸风格的深色抽象渲染）。
* **亚克力效果 (Acrylic/Glassmorphism)**：在背景图之上，覆盖一层半透明的、带有模糊效果的深色蒙层。这将是整个窗口的基底。


2. **居中登录卡片（质感升级）**：
* **卡片本身**：将原有的纯黑卡片改为深灰色（近似 `#1E242C`），并赋予它轻微的**玻璃拟态 (Glassmorphism)** 效果——即卡片本身具有半透明度，能透出底下模糊的背景光影。
* **边框**：给卡片加上一条极细的、高亮度的内描边（例如 `#FFFFFF.withOpacity(0.05)`），模拟金属边缘。
* **阴影**：使用大范围、极淡的扩散阴影（`BoxShadow(color: Colors.black.withOpacity(0.4), blurRadius: 30)`），让卡片看起来是**悬浮**在半空，而不是贴在背景上。


3. **组件细节优化（微交互）**：
* **输入框**：
* 放弃扁平的白色框。使用深色背景的输入框（近似 `#0B0E14`）。
* **获得焦点时**：当用户点击输入框，边框应该变为品牌色（蓝色），并且卡片整体会产生一个极微小的 Z 轴抬升动画。
* **图标**：将左侧的图标（用户、锁）做成灰色，并确保它们与文字对齐。


* **按钮（登录）**：
* 将蓝色按钮的圆角稍微减小（从现在的 16px 减到 8px-12px），看起来更稳重。
* **Hover 效果**：鼠标移上去时，按钮背景色变亮，并增加轻微的“光晕”效果。


* **Logo 和文字**：
* Logo 保持不变，但可以考虑给它加一个非常淡的外发光（Glow），使其更突出。
* "FlashTrade" 文字加粗，颜色设为纯白。
* "登录" 二字颜色设为次要灰色。




4. **交互补充（现代桌面感）**：
* **键盘支持**：确保按下 Enter 键即可触发登录，无需点击按钮。
* **加载状态**：点击登录后，按钮内的文字消失，替换为一个精细的 `CircularProgressIndicator`（颜色为白色，不要用系统默认蓝色）。

### 总结：如何实施？

如果您只有半天时间，建议优先做三件事：

1. **换背景**：找一张深色、有质感的图片做背景，并加上模糊效果。
2. **改卡片颜色**：将白色卡片改为半透明深灰色。
3. **调整按钮圆角**：将圆角从 16px 改为 8px。

## 登录页 UI 设计与优化方案（补充）

要在 Flutter 中生成“科技纹理”背景，最专业且不占用额外资源的方法是使用 **`CustomPainter`** 绘制动态或静态的科技线条（如网格、粒子点、或电路纹理）。这样可以确保背景无限清晰，且文件体积极小。

以下是一个适合金融 App 登录页的**科技感动态背景代码实现方案**：

### 1. 实现思路：极简“深色科技网格”

不要使用图片，使用 `CustomPainter` 在深色背景上绘制微弱的网格和节点，配合 `BackdropFilter` 实现磨砂玻璃质感。

### 2. 核心代码实现

你可以将这个 `TechBackground` 组件放在你登录页的最底层：

```dart
import 'package:flutter/material.dart';
import 'dart:ui';

class TechBackground extends StatelessWidget {
  const TechBackground({super.key});

  @override
  Widget build(BuildContext context) {
    return Container(
      decoration: const BoxDecoration(
        color: Color(0xFF0B0E14), // 极深底色
      ),
      child: Stack(
        children: [
          // 绘制科技纹理层
          CustomPaint(
            painter: TechLinesPainter(),
            child: Container(),
          ),
          // 磨砂效果层
          BackdropFilter(
            filter: ImageFilter.blur(sigmaX: 5, sigmaY: 5),
            child: Container(color: Colors.black.withOpacity(0.2)),
          ),
        ],
      ),
    );
  }
}

class TechLinesPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final paint = Paint()
      ..color = Colors.blue.withOpacity(0.05) // 极淡的蓝色线条
      ..strokeWidth = 1.0;

    // 绘制横线
    for (double i = 0; i < size.height; i += 50) {
      canvas.drawLine(Offset(0, i), Offset(size.width, i), paint);
    }
    // 绘制竖线
    for (double i = 0; i < size.width; i += 50) {
      canvas.drawLine(Offset(i, 0), Offset(i, size.height), paint);
    }
  }

  @override
  bool shouldRepaint(CustomPainter oldDelegate) => false;
}

```

### 3. 如何增加“专业感”纹理？

如果你想要那种高端的“矩阵”或“数据流”感，可以在 `CustomPainter` 中添加以下元素：

* **发光节点**：在横竖线的交叉点绘制小的 `Canvas.drawCircle`，并使用 `MaskFilter.blur` 制造发光效果。
* **非对称分布**：不要让所有线条等距，将间距设为随机数，或者根据屏幕中心进行渐变处理，会让界面看起来不像“Excel 表格”而像“高级监测仪表”。
* **径向渐变 (Radial Gradient)**：在屏幕的一角（例如右上角）添加一个巨大的、半透明的蓝色径向渐变圆点，模拟屏幕的光影。

### 4. 视觉建议

* **颜色控制**：科技感不是靠“彩色”实现的，是靠**颜色的明暗对比**。保持背景为纯黑 (`#0B0E14`)，纹理颜色使用 `#2196F3` (你的品牌蓝) 的极淡透明版 (`0.05` 透明度)。
* **动效**：如果你想更进一步，可以使用 `AnimationController` 让这些线条缓慢地左右平移（速度极慢，每秒 5-10 像素），这种轻微的动态会让用户觉得应用“正在运行”，非常有生产力感。
