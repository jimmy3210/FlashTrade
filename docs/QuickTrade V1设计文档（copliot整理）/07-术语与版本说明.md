# 07-术语与版本说明

## 1. 文档目的

本文件用于说明 QuickTrade V1 设计文档中的核心术语、版本约定和文档使用方式，方便产品、前端、后端和测试人员在同一语境下协作。

## 2. 版本信息

| 版本 | 日期 | 说明 |
| --- | --- | --- |
| V0.1 | 2026-07-11 | 基于原始讨论记录整理出的初版文档结构 |
| V1.0 | 2026-07-11 | 形成可用于开发与评审的 QuickTrade V1 设计文档集合 |

## 3. 术语定义

| 术语 | 定义 |
| --- | --- |
| QuickTrade | 一个面向股票交易场景的轻量化客户端 |
| Broker | 提供行情、账户、下单能力的券商或交易服务提供方 |
| Adapter | 用于把 Broker 的原始接口数据转换为 QuickTrade 内部统一模型的适配层 |
| Quote | 实时行情对象，包含最新价、买卖价、成交量等信息 |
| Order | 订单对象，表示买入、卖出、撤单、改单等交易动作 |
| Position | 当前持仓对象 |
| Account | 账户及资产摘要对象 |
| Watch List | 用户自选股列表 |
| Market Status | 市场开盘/闭市状态 |

## 4. 文档约定

- 文档中的“V1”表示第一个可交付版本，重点覆盖核心交易能力。
- 未明确列出的功能默认不纳入 V1。
- UI 只展示 QuickTrade 的统一数据模型，避免直接依赖 Broker 的字段细节。
- Broker 差异只出现在 Adapter 层，不应散落在 UI 或业务逻辑层。

## 5. 使用建议

- 产品侧可优先阅读功能清单与 UI 设计说明书
- 前端侧建议结合 UI 说明书和 API 对照表查看页面需求
- 后端侧建议结合字段映射与统一数据模型进行接口和 Adapter 实现
- 测试侧可根据功能清单建立验收用例
