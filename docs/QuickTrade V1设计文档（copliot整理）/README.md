# QuickTrade V1 设计文档集

欢迎使用 QuickTrade V1 的设计文档集合。这里是一套经过整理、去除冗余、保留核心内容的文档包，适合用于产品讨论、前端开发、后端开发、测试验收和后续扩展。

## 文档概览

本套文档聚焦于 QuickTrade V1 的核心目标：建立一个可扩展、可维护、可接入不同 Broker 的美股交易系统，并通过统一 API 服务自有 UI 与其他获授权客户端。

- 日期：2026-07-11
- 状态：可用于开发与评审

## 推荐阅读顺序

1. 先阅读 [总体设计说明（汇总版）](15-QuickTrade%20V1%20总体设计说明（汇总版）.md)
2. 再阅读 [项目定位与目标](01-项目定位与目标.md) 和 [UI设计说明书](02-UI设计说明书.md)

4. 最后结合 [接口设计说明](09-接口设计说明.md)、[系统架构](10-系统架构与非功能需求.md)、[数据库设计草案](11-数据库设计草案.md) 和 [验收清单](13-V1验收标准清单.md) 进行开发与验收
