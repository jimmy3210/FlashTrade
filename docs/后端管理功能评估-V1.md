### 1️⃣ 订单管理系统

#### 功能需求
- **订单列表查询** - 查看所有/指定用户的订单
- **订单详情** - 订单状态、执行情况、费用明细
- **订单搜索/过滤** - 按用户、状态、时间、代码等
- **订单操作** - 查看、取消异常订单（管理员权限）
- **订单导出** - 支持 CSV/Excel 导出

#### 数据表
```sql
-- 已存在（需确认数据完整性）
CREATE TABLE orders (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    broker_account_id BIGINT,
    symbol VARCHAR(20),
    side VARCHAR(10),           -- BUY/SELL
    quantity INT,
    order_type VARCHAR(20),     -- MARKET/LIMIT/STOP
    limit_price DECIMAL(10,2),
    status VARCHAR(20),         -- PENDING/FILLED/CANCELLED/REJECTED
    filled_quantity INT,
    average_price DECIMAL(10,2),
    total_value DECIMAL(15,2),
    commission DECIMAL(10,2),
    created_at DATETIME,
    updated_at DATETIME
);
```

#### API 接口
```
GET    /admin/orders                     -- 订单列表（分页、过滤）

GET    /admin/orders/user/{userId}       -- 用户订单列表
DELETE /admin/orders/{orderId}           -- 取消异常订单（管理员）
GET    /admin/orders/export              -- 导出为 CSV
```

#### UI 页面
```
/dashboard/orders

├── 订单详情对话框
│   ├── 基本信息、执行情况、费用
│   └── 操作按钮（取消订单、查看交易记录）
```

### 3️⃣ 审计日志系统

#### 功能需求
- **操作日志** - 记录所有管理员操作（用户创建、账户修改等）
- **登录日志** - 记录所有登录事件（成功/失败、IP、时间）
- **API调用日志** - 记录关键 API 调用（交易、查询等）
- **系统事件日志** - 系统错误、异常、告警事件

#### 数据表
```sql
CREATE TABLE operation_log (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    operation VARCHAR(100),              -- "创建用户", "修改账户"
    target_type VARCHAR(50),              -- "USER", "BROKER_ACCOUNT"
    target_id BIGINT,
    old_value JSON,                       -- 修改前值
    new_value JSON,                       -- 修改后值
    ip_address VARCHAR(45),
    user_agent VARCHAR(500),
    created_at DATETIME
);

CREATE TABLE login_log (
    id BIGINT PRIMARY KEY,
    username VARCHAR(100),
    login_status VARCHAR(20),            -- SUCCESS/FAILED
    ip_address VARCHAR(45),
    device_info VARCHAR(500),
    failed_reason VARCHAR(200),          -- 失败原因
    login_time DATETIME
);

CREATE TABLE api_call_log (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    method VARCHAR(10),                  -- GET/POST/PUT/DELETE
    endpoint VARCHAR(255),
    request_body JSON,
    response_code INT,
    response_time_ms INT,
    created_at DATETIME
);

CREATE TABLE system_event_log (
    id BIGINT PRIMARY KEY,
    event_type VARCHAR(50),              -- ERROR/WARN/INFO/ALERT
    component VARCHAR(100),              -- 组件名
    message VARCHAR(500),
    stack_trace TEXT,
    created_at DATETIME
);
```

#### API 接口
```
GET    /admin/logs/operations            -- 操作日志列表
GET    /admin/logs/operations/{id}       -- 操作日志详情
GET    /admin/logs/login                 -- 登录日志
GET    /admin/logs/api-calls             -- API调用日志
GET    /admin/logs/system-events         -- 系统事件日志
GET    /admin/logs/export                -- 导出日志
DELETE /admin/logs/{id}                  -- 删除日志（仅管理员）
```

#### UI 页面
```
/dashboard/audit-logs
├── 操作日志标签
│   ├── 列表（操作人、操作类型、对象、时间）
│   ├── 详情对话框（显示修改前后对比）
│   └── 过滤器（日期、用户、操作类型）
├── 登录日志标签
│   ├── 列表（用户名、状态、IP、时间）
│   └── 异常登录告警
├── API日志标签
│   └── 列表（端点、用户、响应时间）
└── 系统事件标签
    └── 列表（事件类型、组件、消息、时间）
```

### 4️⃣ 风控管理系统

#### 功能需求
- **风控规则配置** - 单笔限额、日限额、周限额
- **风控规则监控** - 实时监控规则违反情况
- **用户风险评级** - 根据交易行为评级
- **异常交易告警** - 异常模式检测和告警

#### 数据表
```sql
CREATE TABLE risk_control_rules (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    rule_type VARCHAR(50),               -- SINGLE_ORDER/DAILY/WEEKLY
    max_amount DECIMAL(15,2),
    max_quantity INT,
    enabled BOOLEAN,
    created_at DATETIME
);

CREATE TABLE risk_alert (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    alert_type VARCHAR(50),              -- LIMIT_EXCEEDED/UNUSUAL_PATTERN
    message VARCHAR(500),
    severity VARCHAR(20),                -- LOW/MEDIUM/HIGH/CRITICAL
    resolved BOOLEAN,
    created_at DATETIME
);

CREATE TABLE user_risk_rating (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    rating VARCHAR(20),                  -- SAFE/MEDIUM/HIGH/CRITICAL
    last_updated DATETIME,
    score DECIMAL(5,2)
);
```

#### API 接口
```
GET    /admin/risk-rules/{userId}        -- 用户风控规则
POST   /admin/risk-rules/{userId}        -- 创建规则
PUT    /admin/risk-rules/{ruleId}        -- 更新规则
DELETE /admin/risk-rules/{ruleId}        -- 删除规则
GET    /admin/risk-alerts                -- 风控告警列表
PUT    /admin/risk-alerts/{alertId}      -- 解决告警
GET    /admin/user-ratings               -- 用户风险评级
```

#### UI 页面
```
/dashboard/risk-control
├── 风控规则管理
│   ├── 规则列表（用户、规则类型、限额）
│   ├── 创建/编辑规则对话框
│   └── 规则启用/禁用开关
├── 风控告警监控
│   ├── 告警列表（严重级别、类型、时间）
│   ├── 告警详情
│   └── 手动解决告警按钮
└── 用户风险评级
    ├── 评级列表（用户、评级、分数）
    └── 评级历史图表
```

### 5️⃣ 系统监控与告警

#### 功能需求
- **系统健康检查** - CPU、内存、磁盘、数据库连接
- **API 性能监控** - 响应时间、QPS、错误率
- **实时告警** - 性能下降、错误率升高、资源告急
- **告警配置** - 告警阈值、通知渠道

#### 数据表
```sql
CREATE TABLE system_health_metric (
    id BIGINT PRIMARY KEY,
    cpu_usage DECIMAL(5,2),
    memory_usage DECIMAL(5,2),
    disk_usage DECIMAL(5,2),
    db_connection_count INT,
    timestamp DATETIME
);

CREATE TABLE api_performance_metric (
    id BIGINT PRIMARY KEY,
    endpoint VARCHAR(255),
    avg_response_time_ms DECIMAL(8,2),
    max_response_time_ms DECIMAL(8,2),
    error_count INT,
    total_count INT,
    recorded_at DATETIME
);

CREATE TABLE alert_config (
    id BIGINT PRIMARY KEY,
    alert_name VARCHAR(100),
    metric_name VARCHAR(100),
    threshold DECIMAL(10,2),
    operator VARCHAR(10),               -- >, <, >=, <=, ==
    enabled BOOLEAN,
    notification_channels JSON           -- ["email", "webhook"]
);
```

#### API 接口
```
GET    /admin/health                     -- 系统健康状态
GET    /admin/metrics/api-performance    -- API性能指标
GET    /admin/metrics/system-health      -- 系统资源指标
GET    /admin/alerts/active              -- 活动告警列表
POST   /admin/alert-config               -- 创建告警规则
PUT    /admin/alert-config/{id}          -- 修改告警规则
```

#### UI 页面
```
/dashboard/monitoring
├── 系统健康仪表板
│   ├── CPU/内存/磁盘使用率（百分比图）
│   ├── 数据库连接数（实时）
│   └── 综合健康度评分
├── API性能监控
│   ├── 端点性能排行
│   ├── 错误率趋势图
│   └── 性能详情表
└── 告警管理
    ├── 活动告警列表
    ├── 告警规则配置
    └── 告警历史
```

### 6️⃣ 权限和角色管理

#### 功能需求
- **精细化角色定义** - 超管、系统管理员、风控员、查看员
- **权限分配** - 细粒度的功能权限管理
- **用户角色分配** - 为用户分配角色和权限

#### 数据表
```sql
CREATE TABLE t_role (
    id BIGINT PRIMARY KEY,
    role_name VARCHAR(100),              -- ADMIN, RISK_MANAGER, AUDITOR
    role_description VARCHAR(500),
    created_at DATETIME
);

CREATE TABLE t_permission (
    id BIGINT PRIMARY KEY,
    permission_name VARCHAR(100),        -- user.create, order.view
    permission_description VARCHAR(500),
    resource VARCHAR(100),               -- 资源：users, orders, positions
    action VARCHAR(50)                   -- 操作：create, read, update, delete
);

CREATE TABLE t_role_permission (
    role_id BIGINT,
    permission_id BIGINT,
    PRIMARY KEY (role_id, permission_id)
);

CREATE TABLE t_user_role (
    user_id BIGINT,
    role_id BIGINT,
    assigned_at DATETIME,
    PRIMARY KEY (user_id, role_id)
);
```

#### API 接口
```
GET    /admin/roles                      -- 角色列表
POST   /admin/roles                      -- 创建角色
PUT    /admin/roles/{id}                 -- 编辑角色
DELETE /admin/roles/{id}                 -- 删除角色
GET    /admin/permissions                -- 权限列表
GET    /admin/users/{userId}/roles       -- 用户角色
POST   /admin/users/{userId}/roles       -- 分配角色
DELETE /admin/users/{userId}/roles/{id}  -- 移除角色
```

#### UI 页面
```
/dashboard/access-control
├── 角色管理
│   ├── 角色列表
│   ├── 创建/编辑角色
```
