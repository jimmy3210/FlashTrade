## 1. 系统概述

### 功能定位
完整的审计日志系统，记录系统中所有重要操作，用于合规审计、问题诊断和安全追踪。

### 核心功能
- **操作日志** - 记录所有管理员操作（用户创建、账户修改、订单取消等）
- **登录日志** - 记录所有登录事件（成功/失败、IP、时间）
- **API 调用日志** - 记录关键 API 调用（交易、查询等）
- **系统事件日志** - 记录系统错误、异常、告警事件
- **日志查询** - 支持按条件搜索和导出

## 3. 后端实现方案

### 3.1 日志记录的关键位置

#### 📌 操作日志（Operation Log）

在以下操作时记录：

```
✅ 用户管理
  - 创建用户：AdminUserController.createUser()
  - 修改用户：AdminUserController.updateUser()
  - 删除用户：AdminUserController.deleteUser()
  - 启用/禁用：AdminUserController.toggleUserStatus()

✅ 账户管理
  - 创建账户：BrokerAccountAdminController.createAccount()
  - 修改账户：BrokerAccountAdminController.updateAccount()
  - 修改API环境：BrokerAccountAdminController.updateApiEnvironment()
  - 删除账户：BrokerAccountAdminController.deleteAccount()

✅ 订单管理
  - 标记订单：OrderAdminController.markOrder()
  - 取消订单：OrderAdminController.cancelOrder()

✅ 风控管理
  - 更新风控规则：RiskControlController.updateRiskRule()
  - 禁用账户：RiskService.disableAccount()
  - 强制平仓：RiskService.forceLiquidate()
```

#### 📌 登录日志（Login Log）

在认证位置记录：

```
✅ AuthController.login()
  - 登录成功
  - 登录失败（记录失败原因）

✅ TokenService.validateToken()
  - Token 过期
  - Token 无效
```

#### 📌 API 调用日志（API Call Log）

在关键接口记录（通过 AOP 拦截）：

```
✅ 交易相关（标记为 CRITICAL）
  - POST /api/v1/trade/order
  - DELETE /api/v1/trade/order/{id}
  - PUT /api/v1/trade/order/{id}

✅ 管理相关
  - POST /admin/*
  - PUT /admin/*
  - DELETE /admin/*

✅ 查询操作（仅记录错误的调用）
  - GET 请求（如有错误）
```

#### 📌 系统事件日志（System Event Log）

在以下情况记录：

```
✅ 错误事件 (ERROR/CRITICAL)
  - 数据库连接失败
  - 券商API调用失败
  - 交易执行异常
  - 系统崩溃恢复

✅ 告警事件 (WARN/HIGH)
  - 登录失败多次
  - 异常交易模式检测
  - 风控规则触发
  - API响应超时

✅ 关键事件 (INFO)
  - 系统启动/关闭
  - 定时任务执行
  - 数据同步完成
```

#### AuditLogger.java（核心日志工具类）

```java
@Component
@Slf4j
public class AuditLogger {
    
    @Autowired private OperationLogRepository operationLogRepository;
    @Autowired private LoginLogRepository loginLogRepository;
    @Autowired private ApiCallLogRepository apiCallLogRepository;
    @Autowired private SystemEventLogRepository systemEventLogRepository;
    
    /**
     * 记录操作日志
     */
    public void logOperation(Long operatorId, String operatorUsername, String operation,
                            String targetType, Long targetId, String targetName,
                            Object oldValue, Object newValue, String changeSummary,
                            String requestIp, String requestPath, String requestMethod,
                            Integer httpStatus, String userAgent) {
        try {
            OperationLog log = OperationLog.builder()
                .operatorId(operatorId)
                .operatorUsername(operatorUsername)
                .operation(operation)
                .targetType(targetType)
                .targetId(targetId)
                .targetName(targetName)
                .oldValue(oldValue != null ? JSON.toJSONString(oldValue) : null)
                .newValue(newValue != null ? JSON.toJSONString(newValue) : null)
                .changeSummary(changeSummary)
                .requestIp(requestIp)
                .requestPath(requestPath)
                .requestMethod(requestMethod)
                .httpStatus(httpStatus)
                .userAgent(userAgent)
                .build();
            
            operationLogRepository.save(log);
            log.info("Operation logged: op={}, target={}:{}, operator={}", 
                    operation, targetType, targetId, operatorUsername);
            
        } catch (Exception e) {
            log.error("Failed to log operation", e);
        }
    }
    
    /**
     * 记录登录日志
     */
    public void logLogin(String username, Long userId, String loginStatus, 
                        String failedReason, String requestIp, String userAgent,
                        String loginMethod, String sessionId) {
        try {
            LoginLog log = LoginLog.builder()
                .username(username)
                .userId(userId)
                .loginStatus(loginStatus)
                .failedReason(failedReason)
                .requestIp(requestIp)
                .userAgent(userAgent)
                .loginMethod(loginMethod)
                .sessionId(sessionId)
                .build();
            
            loginLogRepository.save(log);
            
            if ("FAILED".equals(loginStatus)) {
                log.warn("Login failed: username={}, reason={}, ip={}", 
                        username, failedReason, requestIp);
            } else {
                log.info("Login successful: username={}, ip={}", username, requestIp);
            }
            
        } catch (Exception e) {
            log.error("Failed to log login", e);
        }
    }
    
    /**
     * 记录API调用日志（异步）
     */
    @Async
    public void logApiCall(Long userId, String username, String httpMethod, 
                          String endpoint, String requestParams, Object requestBody,
                          Integer responseCode, Long responseTimeMs,
                          String requestIp, String userAgent, boolean isCritical) {
        try {
            ApiCallLog log = ApiCallLog.builder()
                .userId(userId)
                .username(username)
                .httpMethod(httpMethod)
                .endpoint(endpoint)
                .requestParams(requestParams)
                .requestBody(requestBody != null ? JSON.toJSONString(requestBody) : null)
                .responseCode(responseCode)
                .responseTimeMs(responseTimeMs.intValue())
                .requestIp(requestIp)
                .userAgent(userAgent)
                .isCritical(isCritical)
                .errorFlag(responseCode >= 400)
                .build();
            
            apiCallLogRepository.save(log);
            
            if (isCritical) {
                log.info("Critical API called: {} {} by user={}, responseTime={}ms",
                        httpMethod, endpoint, username, responseTimeMs);
            }
            
        } catch (Exception e) {
            log.error("Failed to log API call", e);
        }
    }
    
    /**
     * 记录系统事件日志
     */
    public void logSystemEvent(String eventType, String severity, String component,
                              String message, String stackTrace, Long relatedUserId,
                              Long relatedOrderId, String relatedResource) {
        try {
            SystemEventLog log = SystemEventLog.builder()
                .eventType(eventType)
                .severity(severity)
                .component(component)
                .message(message)
                .stackTrace(stackTrace)
                .relatedUserId(relatedUserId)
                .relatedOrderId(relatedOrderId)
                .relatedResource(relatedResource)
                .resolved(false)
                .build();
            
            systemEventLogRepository.save(log);
            
            // 根据严重级别输出不同日志
            if ("CRITICAL".equals(severity) || "HIGH".equals(severity)) {
                log.error("System event [{} - {}]: {} | Component: {} | Resource: {}",
                        eventType, severity, message, component, relatedResource);
            } else if ("WARN".equals(severity)) {
                log.warn("System event [{} - {}]: {} | Component: {}",
                        eventType, severity, message, component);
            } else {
                log.info("System event [{} - {}]: {} | Component: {}",
                        eventType, severity, message, component);
            }
            
        } catch (Exception e) {
            log.error("Failed to log system event", e);
        }
    }
}
```

#### AuditLogAspect.java（AOP 拦截器，自动记录API调用）

```java
@Aspect
@Component
@Slf4j
public class AuditLogAspect {
    
    @Autowired private AuditLogger auditLogger;
    @Autowired private AuthService authService;
    @Autowired private ClientIpResolver clientIpResolver;
    
    /**
     * 拦截所有 /admin 和 /api/v1/trade 的操作
     */
    @Around("execution(* com.tradex.flashtrade.controller.admin..*(..)) || " +
            "execution(* com.tradex.flashtrade.controller.TradeController.*(..))")
    public Object logApiCall(ProceedingJoinPoint joinPoint) throws Throwable {
        HttpServletRequest request = getRequest();
        long startTime = System.currentTimeMillis();
        
        try {
            // 获取用户信息
            Long userId = authService.getCurrentUserId();
            String username = authService.getCurrentUsername();
            
            // 获取请求信息
            String httpMethod = request.getMethod();
            String endpoint = request.getRequestURI();
            String requestIp = getClientIp(request);
            String userAgent = request.getHeader("User-Agent");
            
            // 执行方法
            Object result = joinPoint.proceed();
            
            // 记录成功的调用
            long responseTime = System.currentTimeMillis() - startTime;
            boolean isCritical = endpoint.contains("/trade/order") || endpoint.contains("/admin/");
            
            auditLogger.logApiCall(userId, username, httpMethod, endpoint, null, null,
                    200, responseTime, requestIp, userAgent, isCritical);
            
            return result;
            
        } catch (Exception e) {
            long responseTime = System.currentTimeMillis() - startTime;
            
            // 记录失败的调用
            log.error("API call error: {} {} - {}", 
                    request.getMethod(), request.getRequestURI(), e.getMessage());
            
            auditLogger.logApiCall(authService.getCurrentUserId(), 
                    authService.getCurrentUsername(),
                    request.getMethod(), request.getRequestURI(), null, null,
                    500, responseTime, getClientIp(request), 
                    request.getHeader("User-Agent"), true);
            
            throw e;
        }
    }
    
    private HttpServletRequest getRequest() {
        ServletRequestAttributes attrs = 
            (ServletRequestAttributes) RequestContextHolder.getRequestAttributes();
        return attrs.getRequest();
    }
    
    private String getClientIp(HttpServletRequest request) {
        return clientIpResolver.resolve(request);
    }
}
```

```java
public OrderAdminDto markOrder(Long orderId, String riskFlag, String adminNote, Long adminId) {

    order.setRiskFlag(riskFlag);
    order.setAdminNote(adminNote);
    order.setAdminId(adminId);
    order.setAdminActionTime(LocalDateTime.now());
    
    Order updated = orderRepository.save(order);
    log.info("✅ Order marked successfully: orderId={}, oldFlag={}, newFlag={}",

    return convertToAdminDto(updated);

@Transactional
public OrderAdminDto cancelOrder(Long orderId, String reason, Long adminId) {
    log.warn("⚠️  Admin cancelling order: orderId={}, reason={}, adminId={}, timestamp={}",
            orderId, reason, adminId, LocalDateTime.now());
    
    Order order = orderRepository.findById(orderId)
        .orElseThrow(() -> {
            log.error("❌ Order not found for cancellation: orderId={}", orderId);
            return new BusinessException("订单不存在", ErrorCode.NOT_FOUND);
        });
    
    if ("FILLED".equals(order.getStatus()) || "CANCELLED".equals(order.getStatus())) {
        log.error("❌ Cannot cancel order with status: orderId={}, status={}", 
                orderId, order.getStatus());
        throw new BusinessException("订单状态不允许取消", ErrorCode.INVALID_STATE);
    }
    
    String oldStatus = order.getStatus();
    order.setStatus("CANCELLED");
    order.setRiskFlag("CANCELLED_BY_ADMIN");
    order.setAdminNote(reason);
    order.setAdminId(adminId);
    order.setAdminActionTime(LocalDateTime.now());
    
    Order updated = orderRepository.save(order);
    log.warn("✅ Order cancelled by admin: orderId={}, oldStatus={}, reason={}", 
            orderId, oldStatus, reason);
    
    return convertToAdminDto(updated);
}
```

```java
@Transactional
public BrokerAccountDto setCurrentAccountForUser(Long userId, Long accountId) {
    log.info("🔄 Setting current account for user: userId={}, accountId={}", userId, accountId);
    
    try {
        User user = userRepository.findById(userId)
            .orElseThrow(() -> {
                log.error("❌ User not found: userId={}", userId);
                return new BusinessException("用户不存在", ErrorCode.NOT_FOUND);
            });
        
        BrokerAccount account = brokerAccountRepository.findById(accountId)
            .orElseThrow(() -> {
                log.error("❌ Broker account not found: accountId={}", accountId);
                return new BusinessException("账户不存在", ErrorCode.NOT_FOUND);
            });
        
        if (!"ACTIVE".equals(account.getStatus())) {
            log.error("❌ Account not active: accountId={}, status={}", accountId, account.getStatus());
            throw new BusinessException("账户非活跃状态: " + account.getStatus(), 
                    ErrorCode.INVALID_ARGUMENT);
        }
        
        // 检查账户是否被其他用户占用
        User existingUser = userRepository.findByCurrentBrokerAccountId(accountId);
        if (existingUser != null && !existingUser.getId().equals(userId)) {
            log.error("❌ Account already bound to another user: accountId={}, boundUserId={}", 
                    accountId, existingUser.getId());
            throw new BusinessException("账户已被其他用户绑定", ErrorCode.CONFLICT);
        }
        
        Long oldAccountId = user.getCurrentBrokerAccountId();
        user.setCurrentBrokerAccountId(accountId);
        userRepository.save(user);
        
        log.info("✅ Current account updated: userId={}, oldAccountId={}, newAccountId={}", 
                userId, oldAccountId, accountId);
        
        return convertToDto(account);
        
    } catch (Exception e) {
        log.error("❌ Error setting current account: userId={}, accountId={}", userId, accountId, e);
        throw e;
    }
}
```

## 5. 日志级别和关键位置总结

| 位置 | 级别 | 样例 | 目的 |
|------|------|------|------|
| 标记订单 | WARN | `log.warn("📝 Admin marking order: ...")` | 监控风险操作 |
| 取消订单 | WARN | `log.warn("⚠️  Admin cancelling order: ...")` | 监控取消操作 |
| 账户绑定 | INFO | `log.info("✅ Current account updated: ...")` | 审计跟踪 |
| 操作成功 | INFO | `log.info("✅ Order marked successfully: ...")` | 操作确认 |
| 操作失败 | ERROR | `log.error("❌ Order not found: ...")` | 问题诊断 |
| 状态检查 | ERROR | `log.error("❌ Cannot cancel order with status: ...")` | 业务错误 |
| API异常 | ERROR | `log.error("API call error: ...", e)` | 故障恢复 |
| 系统告警 | WARN | `auditLogger.logSystemEvent(..., "WARN", ...)` | 运维监控 |
| 系统故障 | ERROR | `auditLogger.logSystemEvent(..., "CRITICAL", ...)` | 严重告警 |

## 6. 日志配置（logback-spring.xml）

```xml
<!-- 关键日志的独立输出 -->

<!-- 审计日志文件 -->
<appender name="AUDIT_LOG_FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
    <file>logs/audit/audit.log</file>
    <encoder>
        <pattern>%d{yyyy-MM-dd HH:mm:ss} | %level | %logger{36} | %msg%n</pattern>
    </encoder>
    <rollingPolicy class="ch.qos.logback.core.rolling.TimeBasedRollingPolicy">
        <fileNamePattern>logs/audit/audit.%d{yyyy-MM-dd}.%i.log</fileNamePattern>
        <timeBasedFileNamingAndTriggeringPolicy class="ch.qos.logback.core.rolling.SizeAndTimeBasedFNATP">
            <maxFileSize>500MB</maxFileSize>
        </timeBasedFileNamingAndTriggeringPolicy>
        <maxHistory>90</maxHistory>
    </rollingPolicy>
</appender>

<!-- 错误日志文件 -->
<appender name="ERROR_LOG_FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
    <file>logs/error/error.log</file>
    <filter class="ch.qos.logback.classic.filter.ThresholdFilter">
        <level>ERROR</level>
    </filter>
    <encoder>
        <pattern>%d{yyyy-MM-dd HH:mm:ss} | %level | %logger{36} | %msg | %ex%n</pattern>
    </encoder>
    <rollingPolicy class="ch.qos.logback.core.rolling.TimeBasedRollingPolicy">
        <fileNamePattern>logs/error/error.%d{yyyy-MM-dd}.%i.log</fileNamePattern>
        <maxHistory>30</maxHistory>
    </rollingPolicy>
</appender>

<!-- Logger 配置 -->
<logger name="com.tradex.flashtrade.service.OrderAdminService" level="INFO">
    <appender-ref ref="AUDIT_LOG_FILE" />
</logger>

<logger name="com.tradex.flashtrade.service.AuditLogger" level="INFO">
    <appender-ref ref="AUDIT_LOG_FILE" />
</logger>

<!-- 根日志 -->
<root level="INFO">
    <appender-ref ref="CONSOLE" />
    <appender-ref ref="FILE" />
    <appender-ref ref="ERROR_LOG_FILE" />
</root>
```

```
GET /admin/logs/login
```

```
GET /admin/logs/api-calls
```

```
GET /admin/logs/system-events
    ?page=1&pageSize=20&eventType={type}&severity={level}&resolved={flag}
```
