# Flash-Trade 管理端功能文档

## 概述

`flash-trade-admin` 是系统的后台管理端，基于 **Vue 3 + TypeScript + Vite**，面向内部管理员和风控人员。

## 功能模块

### 1. 在仓管理 (Position Management)
**页面**: `/dashboard/positions`

#### 功能
- 查询全部用户的仓位聚合视图（按用户、券商、标的分组）
- 显示关键信息：数量、均价、现价、市值、未实现 PnL、更新时间

#### API 接口
- `GET /admin/positions` - 获取全量仓位或按 accountId 过滤

---

### 2. 用户管理 (User Management)
**页面**: `/dashboard/users`, `/dashboard/users/create`, `/dashboard/users/:id/edit`, `/dashboard/users/:id/view`

#### 功能
- **列表**: 查看所有用户及其默认券商账户、状态
- **创建**: 新建用户并关联一个默认券商账户（`t_broker_account`），API 环境默认为 **LIVE**
- **编辑**: 修改用户名、密码、默认券商账户信息
- **启用/停用**: 切换用户 `enabled` 状态

#### 数据流
- 新建/编辑用户时触发 `AdminUserService.createOrUpdateBrokerAccount()`:
  - 若用户已有 `t_broker_account` 记录，则更新 `broker_id` 和 `account_no`
  - 否则插入新记录，`account_type='CASH'`, `api_environment='LIVE'`

#### API 接口
- `GET /users` - 用户列表
- `GET /users/{id}` - 用户详情
- `POST /users` - 创建用户
- `PUT /users/{id}` - 更新用户
- `POST /users/status` - 切换启用状态
- `POST /users/{id}/password` - 修改密码

---

### 3. 券商账户管理 (Broker Account Management) - **新增**
**页面**: `/dashboard/broker-accounts`, `/dashboard/broker-accounts/create`, `/dashboard/broker-accounts/:id/edit`, `/dashboard/broker-accounts/:id/view`

#### 功能
- **列表**: 查看全部用户的券商账户绑定情况
  - 显示: 账户 ID、用户、券商、账户号、类型、状态、**API 环境**、开发者账号
- **创建**: 为指定用户创建新的券商账户绑定
  - 支持设置 `account_type` (CASH/MARGIN)
  - 支持设置 `status` (ACTIVE/SUSPENDED/CLOSED)
  - 支持设置 `api_environment` (LIVE/SANDBOX) - **灵活控制每个账户的交易环境**
  - 支持关联开发者账号 `dev_account_id`
- **编辑**: 修改券商账户的所有属性，包括 API 环境
- **停用**: 将账户状态标记为 CLOSED

#### 数据模型 (`t_broker_account`)
```sql
id                BIGINT        -- 主键
user_id           BIGINT        -- 用户 ID (FK to users)
broker_id         BIGINT        -- 券商 ID (FK to t_broker)
account_no        VARCHAR(100)  -- 券商内部账号
account_type      VARCHAR(20)   -- CASH / MARGIN
status            VARCHAR(20)   -- ACTIVE / SUSPENDED / CLOSED
dev_account_id    BIGINT        -- 开发者账号 ID (可选, FK to t_broker_dev_account)
api_environment   VARCHAR(20)   -- LIVE / SANDBOX (新增字段，V17 迁移)
created_at        DATETIME      -- 创建时间
```

#### API 接口 - `BrokerAccountAdminController`
- `GET /admin/broker-accounts` - 券商账户列表
- `GET /admin/broker-accounts/{id}` - 券商账户详情
- `POST /admin/broker-accounts` - 创建券商账户
- `PUT /admin/broker-accounts/{id}` - 更新券商账户
- `DELETE /admin/broker-accounts/{id}` - 停用券商账户（标记为 CLOSED）

#### 请求示例
```json
POST /admin/broker-accounts
{
  "userId": 1,
  "brokerName": "schwab",
  "accountNo": "ACH123456",
  "accountType": "CASH",
  "status": "ACTIVE",
  "apiEnvironment": "SANDBOX",
  "devAccountId": null
}
```

---

### 4. 券商配置 (Broker Configuration)
**页面**: `/dashboard/brokers`

#### 功能
- **全局券商 API 模式配置**（适用于所有用户）
  - 模式: PRODUCTION / SANDBOX / MOCK
  - Mock 开关: 是否启用 Mock 模式
  - 自定义 API Base URL

#### 数据流
- 全局配置存储在 `t_broker_runtime_config`
- 优先级: 全局配置 > 默认 Properties 配置

#### API 接口
- `GET /admin/brokers/configs` - 所有券商的全局配置
- `GET /admin/brokers/configs/{brokerName}` - 单个券商配置
- `PUT /admin/brokers/configs/{brokerName}` - 更新券商配置

## 数据库迁移

### V17: 为券商账户添加 API 环境字段
```sql
ALTER TABLE t_broker_account
    ADD COLUMN api_environment VARCHAR(20) NULL COMMENT 'API 环境：LIVE / SANDBOX';

UPDATE t_broker_account
   SET api_environment = 'LIVE'
 WHERE api_environment IS NULL;
```

## 认证与授权

所有管理端接口都需要 JWT Token，并由 Java API 独立完成授权。用户与券商账户 GET 查询按已认证公司管理员的 `users.company_id` Scope 过滤；用户、账户的创建、更新、停用、密码修改和绑定操作仅允许 `ROLE_SUPER_ADMIN`。Web 路由与按钮限制只改善 UX，不构成授权边界。

## 前端请求示例

### 创建用户
```typescript
const response = await request.post('/users', {
  username: 'trader1',
  accountUserId: 'ACC123',
  brokerName: 'schwab',
  companyId: 42,
  password: 'secret123'
});
// 返回: UserAdminDto { userId, username, accountUserId, brokerName, companyId, companyName, role, deleteFlag }
```

### 创建券商账户
```typescript
const response = await request.post('/admin/broker-accounts', {
  userId: 1,
  brokerName: 'etrade',
  accountNo: 'ETR456',
  accountType: 'MARGIN',
  status: 'ACTIVE',
  apiEnvironment: 'SANDBOX'
});
// 返回: BrokerAccountDto { id, userId, username, brokerId, brokerCode, brokerName, accountNo, accountType, status, devAccountId, apiEnvironment }
```

### 更新券商账户 API 环境
```typescript
const response = await request.put(`/admin/broker-accounts/${accountId}`, {
  userId: 1,
  brokerName: 'etrade',
  accountNo: 'ETR456',
  accountType: 'MARGIN',
  status: 'ACTIVE',
  apiEnvironment: 'LIVE',  // 切换回 LIVE
  devAccountId: null
});
```

## 架构设计

### 后端栈
- **Spring Boot** + **Spring Security** + **Spring Data JDBC**
- **JWT Token** 认证
- **Swagger/OpenAPI** 文档

### 前端栈
- **Vue 3** Composition API + `<script setup>`
- **TypeScript** 类型安全
- **Vue Router** 路由
- **Axios** 请求封装，自动解包 `ApiResponse` 和注入 Token

### 数据模型
- `users` - 用户基表
- `t_broker` - 券商主数据
- `t_broker_dev_account` - 开发者账号（App Key/Secret）
- `t_broker_account` - **用户-券商账户绑定**（支持 API 环境选择）
- `t_broker_account_permission` - 账户权限
- `t_broker_runtime_config` - **全局券商运行时配置**

---

## 关键特性

| 特性 | 范围 | 存储位置 | 说明 |
|------|------|---------|------|
| **全局 API 模式** | 所有用户 | `t_broker_runtime_config.mode` | PRODUCTION / SANDBOX / MOCK |
| **全局 Mock 开关** | 所有用户 | `t_broker_runtime_config.mock_enabled` | 所有券商统一使用 Mock |
| **全局 API URL** | 所有用户 | `t_broker_runtime_config.base_url` | 自定义 API 端点 |
| **用户券商账户绑定** | 单个用户 | `t_broker_account` | 一对多关系 |
| **账户 API 环境** | 单个账户 | `t_broker_account.api_environment` | LIVE / SANDBOX（**新增**） |

## 已知缺口 ⚠️

### 交易端未使用账户级 API 环境
**现状**: 
- 各 `BrokerClient` 和 `RestClient` 仅使用 `BrokerConfigService.getEffectiveBaseUrl()` 获取**全局** API URL
- **未查询** `t_broker_account.api_environment`

**改进需求**:
- 交易端需要在调用券商 API 前，根据 **用户 + 账户** 查询 `api_environment`
- 当 `api_environment='SANDBOX'` 时，切换到对应的 Sandbox 端点（如 E*TRADE Sandbox）
- 该改进涉及 `TradeController`, `PortfolioController` 等业务控制器
